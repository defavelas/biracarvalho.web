# Política de Segurança

## Reportando Vulnerabilidades

A segurança do **Programa Bira Carvalho** é uma prioridade. Se você descobrir uma vulnerabilidade de segurança, pedimos que **não** utilize canais públicos como issues do GitHub para reportá-la.

### Como Reportar

Para reportar uma vulnerabilidade de segurança, envie um e-mail detalhado para a equipe de desenvolvimento. Inclua as seguintes informações:

- Descrição da vulnerabilidade
- Passos para reproduzir o problema
- Potencial impacto da vulnerabilidade
- Sugestões de correção (se houver)

### O que Esperar

- Todas as vulnerabilidades reportadas serão analisadas prontamente
- Você receberá uma confirmação de recebimento
- A equipe trabalhará na correção antes de qualquer divulgação pública
- Manteremos você informado sobre o progresso da correção

## Divulgação Responsável

Pedimos que os pesquisadores de segurança:

- **Não** divulguem publicamente a vulnerabilidade antes da correção
- **Não** explorem a vulnerabilidade além do necessário para demonstrá-la
- **Não** acessem ou modifiquem dados de outros usuários
- Aguardem um prazo razoável para a correção antes de qualquer divulgação

## Versões Suportadas

| Versão | Suportada |
|--------|-----------|
| Última versão estável | :white_check_mark: |
| Versões anteriores | :x: |

Recomendamos sempre utilizar a versão mais recente do projeto para garantir que você tenha as últimas correções de segurança.

## Boas Práticas de Segurança

Ao utilizar ou contribuir com o projeto, siga estas práticas:

- Mantenha suas dependências atualizadas
- Nunca commite credenciais ou tokens no repositório
- Use variáveis de ambiente para informações sensíveis
- Revise o código em busca de vulnerabilidades comuns (OWASP Top 10)

## Agradecimentos

Agradecemos a todos que contribuem para manter o Programa Bira Carvalho seguro. Sua ajuda é fundamental para proteger os dados e a privacidade dos usuários da plataforma.
